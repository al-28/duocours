# Duocours

Duocours is an adaptive learning platform that turns a learning goal into a structured course and adapts practice to the learner.

## Development

```bash
npm install
npm run dev
```

## Architecture

- Next.js + React + TypeScript
- Supabase for persistence/authentication (Phase 2)
- Zod for runtime validation
- AI curriculum generation (Phase 3)
- Adaptive learning engine (Phase 4+)

## Quality rule

Every feature follows: inspect → implement → type-check → lint → test → verify → commit.
